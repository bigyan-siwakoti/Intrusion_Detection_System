- `175.45.176.2:46430 -> 149.171.126.10:9111` sent `POST /invoker/EJBInvokerServlet`. This is the JBoss EJB invoker servlet — unauthenticated management/RMI access (**CVE-2007-1036** family) and the endpoint abused for marshalled-object RCE.
- Deployed ET rules 2017573/2017574 only match once a marshalled-object payload is present, so the bare probe fired **no alert**. **True positive, coverage gap → fixed (SID 1100011).**

### 3.5 SMB null-session enumeration + SMB2.0 DoS (covered)
- SMB app-layer events show the attacker negotiating SMB1, doing `SESSION_SETUP_ANDX` with empty credentials, `TREE_CONNECT_ANDX` to `IPC$`, and `NT_CREATE_ANDX`/`READ/WRITE_ANDX` on `\BROWSER`, `\SRVSVC`, `\LSARPC` named pipes — classic null-session RPC enumeration. Covered by IPC$ rules. SID 2009886 (SMB2.0 DoS) fired 122 times against `149.171.126.17:445`. **True positives, covered.**

### 3.6 PPTP flood + Start-Control-Request overflow (covered)
- SID 2126 fired 62 times (`175.45.176.2 -> 149.171.126.14:1723`, etc.); SID 2009976 (Siemens) fired 106 times on the same PPTP flood to `149.171.126.19:1723`. UNSW 1100004 already models the flood. **Covered; Siemens rule is a product mismatch (below).**

### 3.7 Other covered attacks
POP3 external mail retrieval (UNSW 1100005/1100008), RIP flood (1100003), SIP INVITE/REGISTER scan (1100006/1100007), DNS query flood (1100009), Cisco IOS HTTP config attempt (1250), FTP command/PASS overflow and format string (GPL rules), TFTP Get/Put + TFTPGUI overflow, RPC portmap enumeration, SNMP public/private, TELNET login overflow, and Metasploit bind-shell shellcode (ET rules) are all **detected by the loaded baseline or prior UNSW rules**.

## 4. Actions taken — new detection rules

## 6. Coverage gaps identified

1. **IIS Unicode folder traversal file disclosure (CVE-2000-0884)** — no rule matched `%c0%ae…/boot.ini`. **Now covered by SID 1100010.**
2. **JBoss `EJBInvokerServlet` bare probe** — deployed ET rules only catch the marshalled-object RCE stage, not the recon probe. **Now covered by SID 1100011.**
3. **External SMTP spam/relay to internal mail servers** — attacker hosts send SMTP mail (random HELO/mail_from/rcpt_to) to `149.171.126.0/24:25`; no SMTP-specific rule covers this, only the incidental `x86 inc ecx NOOP` content matches.
4. **BGP port-179 scan/reset flood detection is noisy** — SID 2523 emits ~2 alerts per probe (1,668 total). A thresholded UNSW rule (`count 30, seconds 60` by_src, similar to 1100003/1100009) would summarise this more usefully than the per-packet Snort rule.
5. **Shellcode NOP-sled rules** are the top noise source (1,927 + 214 + 101 + …). I did **not** recommend suppressing them because they also flag genuine shellcode, but thresholding by app-protocol (e.g. SMTP) is a candidate tuning decision.
