Abstract

Intrusion detection only catches what its rules describe. In our open-source pipeline an AI model plays the security analyst: it investigates alerts, then writes and tests rules. We scored it on answer keys it never saw.

Background

AI is expected to make attacks more frequent and effective (NCSC, 2024), while defenders drown in alerts.

Our question: can the same AI do the analyst’s job, and what does it need to know?

Objectives

  • Build an AI analyst
  • Measure every rule it writes
  • Test what context it needs
  • Compare it with human experts’ rules
