- `ET EXPLOIT Microsoft SRV2.SYS … (CVE-2009-3103)` (3) — `.3 → .17:445`. Covered.
- `GPL NETBIOS SMB DCERPC LSASS DsRolerUpgradeDownlevelServer exploit` (4) and `IPC$ share access` (34) — SMB share/DCERPC exploitation. Covered.
- DCERPC app-layer events show BIND/BINDACK then REQUEST with large stubs (e.g., 4,000-byte stub, `opnum 1`) — consistent with exploit attempts. Covered.

### 3.7 PPTP attacks
- `OS-WINDOWS PPTP Start Control Request buffer overflow` (62): `.3 → .19:1723` crafted control requests.
- PPTP flood: `.2 → .15:1723` — **154,171 bytes to server, only 1,308 back**. Covered by UNSW `sid:1100004` (fired).
- The `ET EXPLOIT Siemens Gigaset SE361 WLAN Data Flood DoS` rule (105) fires on this same PPTP flood — **product-mismatch false positive** (the victim is a PPTP server, not a Siemens WLAN router). See proposed action below.

### 3.8 SIP, RIP, TFTP, Web recon
- SIP INVITE/REGISTER scans (24+16) — covered by UNSW 1100006/1100007.
- RIP UDP flood (16) — covered by UNSW 1100003.
- TFTP `Get/Put`, `GET passwd`, filename overflow, parent-directory traversal — covered by GPL/PROTOCOL rules.
- HTTP: `server-status` (200), `cmd.exe`, SQLi (`SELECT USER`), RFI, `Cisco IOS HTTP configuration` — covered by ET/GPL rules.

## 4. Actions taken

### 4.1 Detection rule written (threat, previously undetected)
Appended to `rules/generated/unsw/rounds_research.rules`:

```
alert tcp $EXTERNAL_NET any -> $HOME_NET 110 (msg:"UNSW external POP3 mail retrieval (RETR) port-based"; flow:to_server,established; content:"RETR"; nocase; depth:4; classtype:attempted-recon; sid:1100012; rev:1;)
```

Validated by re-running Suricata: **111 alerts**, all attacker→internal POP3:110. The rule catches mail exfiltration that the target run produced **zero** alerts for.

### 4.2 False-positive suppress proposal (for engineer approval — not written)
```
# Product mismatch: rule targets Siemens Gigaset SE361 WLAN router, but on this
# network it fires on PPTP (TCP/1723) flood traffic to internal PPTP servers.
# The actual PPTP flood is already covered by UNSW sid 1100004.
suppress gen_id 1, sig_id 2009976
```

## 5. Coverage gaps identified

1. **POP3 mail exfiltration** — 253 app-layer events, 0 alerts in the target run. **Fixed** with sid 1100012 (validated).
2. **External WebDAV executable retrieval** — attackers issue `PROPFIND`/`GET` for `.exe`/`.dll`/`.bat` files (`packager.exe`, `cmd.exe`, `dwmapi.dll`, `wlanapi.dll`, `ehtrace.dll`, …) against internal HTTP servers with **200/207 success**, but no WebDAV/PROPFIND alert fired. Loaded ET rules (`2047742` "WebDAV Retrieving .exe", `2047743` ".dll", `2011457`) did not match — likely a direction/flowbits mismatch (they target victim→attacker WebDAV downloads, not attacker→HOME_NET retrieval). Worth a dedicated rule.
3. **SMTP generic/spam transaction flood** — attackers send large numbers of randomized `HELO/MAIL FROM/RCPT TO` transactions to internal SMTP:25 (one with a format-string in `RCPT TO`). Only the generic 'A'-flood shellcode rules fire; there is no SMTP-specific spam/relay-abuse alert.
4. **Baseline config issues observed in `run.out`** (not modified, read-only):
   - `SIP_SERVERS` is undefined, so several VOIP rules fail to load (compensated by UNSW 1100006/1100007).
   - `threshold-config` failed to open (empty path), so the suppress lines in `config/threshold.config` are not applied — this is why stream/parser noise (e.g., `STREAM ESTABLISHED packet out of window`) still appears in the alert stream.

## 6. Bottom line
This capture is a multi-vector attack scenario from `175.45.176.0/24` against internal servers: BGP reset DoS, SMTP/FTP/IMAP/TFTP overflow fuzzing, FTP traversal exfiltration, POP3 mail theft, SMB/DCERPC exploits, PPTP flood/overflow, RIP/SIP floods, and web recon. Most attacks were already detected. The one confirmed attack with **zero alert coverage** — POP3 mail exfiltration — now has a validated detection rule (sid 1100012). I also proposed suppressing the Siemens-Gigaset false positive (sid 2009976) pending approval.
